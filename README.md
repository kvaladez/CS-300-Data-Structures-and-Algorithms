# CS-300-Analysis and Design
CS-300 Data Structures and Algorithm Portfolio

1. What was the problem you were solving in the projects for this course?
The main problem I was solving during this course was how to organize and retrieve information efficiently, specifically for the project assigned for the ABCU advising program. 
The goal was not only to create a program that could display courses and their prerequisites, but also to understand how different data structures affect the performance of a program.
One of the biggest challenges for me was learning how to analyze runtime complexity and compare different structures such as vectors, hash tables, and binary search trees, and to 
determining which would best meet the program's requirements.

2. How did you approach the problem? Consider why data structures are important to understand.
I approached the problem by first learning how different structures work, store, organize and retrieve the information.
In Project one, I created a pseudocode for three different data structures, vector, hash table and binary search tree. I then analyzed their runtime complexity and compared their advantages
and disadvantages to determine which structure would be more suitable for the advising program's requirements. This helped me understand that choosing a data structure is not only about 
how fast it runs but also about how well it meets the requirements. The ABCU advising program required courses to be displayed in alphanumeric order and the Binary Search Tree fulfilled 
this requirement by organizing courses based on their course numbers allowing them to be shown in the correct order without needing to sort each one. Therefore, choosing the Binary Search Tree, 
out of the three structures, for the ABCU advising program made the most sense.

3. How did you overcome any roadblocks you encountered while going through the activities or project?
One of the challenges I faced during this course was fully understanding runtime complexity, what is for and how is it measured, as well as how to use it to analyze the efficiency of different
data structures. I overcame this by breaking down each pseudocode step by step and used the runtime analysis charts to better understand how often each operation would execute. Another challenge
that occurred while testing my Project Two program in Visual Studio, was when the menu started printing repeatedly without stopping. After reviewing the code, I learned that the problem was 
caused by the program not being able to properly handle invalid input, from the document provided. To fix this, I modified the code to detect input errors, clear the error state and allow 
the user to enter another menu option. This experience taught me the importance of debugging, testing different scenarios and making sure a program can handle unexpected input.

4. How was your work on this project expanded your approach to designing software and developing programs?
Working on these projects helped me change the way I approach designing and developing software. Before this course I mostly focused on writing code that would simply achieve its goal and 
that it worked correctly, but now I see the importance in planning and evaluating different solutions to be able to pick the most efficient one. Creating pseudocode and analyzing the runtime 
of different data structures helped me understand how design decisions can affect a program's performance and efficiency. It also helped me learn that choosing the right data structure for 
what the program needs to accomplish is more important rather than just choosing what is the easiest option to create. I will now focus on the program's requirements, create and analyze 
different solutions, before choosing and developing the code.

5. How has your work on this project evolved the way you write programs that are maintainable, readable and adaptable?
These projects have helped me understand that writing code is not only about functionality but also about the importance of creating a code that is easy to read, understand, maintain and modify.
During Project Two, I tried my best to organize my code into separate functions and adding comments to explain every section of the code. This made it easier for me to understand and keep track 
of each portion of the code, so it was easier to debug and modify. Separating the functions for loading course information, searching for courses and to display course, makes the code easier to
modify by parts without affecting other sections of the code. I will continue to apply what I have learned in this course by writing a code that is easy to follow, is organized into separate 
sections and is simple enough to modify with ease.
